# About the project
This is a small CLI Linux program that prints out your RAM updating every second.
### Requirements
Linux<br>
### Built with
GCC<br><hr>
# Getting started
## Usage
1. Make sure you're a Linux <strike>femboy user with unwashed hair</strike>.
2. Clone the rep
```sh
git clone https://github.com/nerd88/ram_monitor.git
```
3. Compile
```sh
gcc ram.c -o ramviewer
```
4. Run
```sh
./ramviewer
```
